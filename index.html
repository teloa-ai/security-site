Enterprise Agent Identity and Authorization Security Baseline

An enterprise agent identity and authorization security baseline and self-assessment tool derived from Teloa development, maintained by Teloa AI Security. It provides open requirements, reference architectures, and maturity assessment for agent platforms.

The baseline is an independent, self-hostable open-source project; this portal provides only a demo. Self-assessment helps review evidence and identify gaps. The project introduction does not establish that Teloa meets every requirement.
